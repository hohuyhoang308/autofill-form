# Script Tự Động Điền Form

Script Tampermonkey tự động điền các biểu mẫu trên forms.office.com với đánh giá "Rất hài lòng".

## Tính năng

- Tự động chọn "Công nghệ Thông tin"
- Tự động điền các trường biểu mẫu
- Chọn tất cả đánh giá "Rất hài lòng"
- Gửi biểu mẫu và có thể tiếp tục phản hồi tiếp theo
- Phím tắt:
  - Nhấn phím `` ` `` để bắt đầu quy trình tự động hóa đầy đủ
  - Nhấn phím `1` để chỉ chọn tất cả tùy chọn "Rất hài lòng" và gửi

## Cài đặt

1. Cài đặt tiện ích [Tampermonkey](https://www.tampermonkey.net/) cho trình duyệt của bạn
2. Nhấp vào nút bên dưới để cài đặt script:

[![Cài đặt Script](https://img.shields.io/badge/Cài%20đặt-Script-blue.svg)](https://raw.githubusercontent.com/tennhcủa bạn/autofill-form-userscript/main/autofill.user.js)

## Cách sử dụng

1. Truy cập trang Microsoft Forms
2. Nhấn phím `` ` `` để bắt đầu quy trình tự động hoàn toàn
3. Hoặc nhấn phím `1` để chỉ chọn tất cả đánh giá "Rất hài lòng" và gửi
